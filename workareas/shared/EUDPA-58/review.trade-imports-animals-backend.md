# Repository Review: trade-imports-animals-backend

**PR:** #67
**Commit:** 54f9f3f
**Files Changed:** 28

## Summary

Adds the EUDPA-293 operator-existence check: notifications gain `operatorId`, `telephone` and `email` on the operator/transporter model, a new `OperatorsApiClient` classifies each operator id against the address-book service, the read path degrades open (flagging unresolved parties) while submit fails closed, and the outbox `schemaVersion` bumps 1 to 2. The shape of the feature is well judged — existence-only, DELETED kept distinct from 404, degrade-open on read and fail-closed on submit. The problems are in the wiring: a shared mutable `RestClient.Builder`, an env-var name that does not match what the stack sets, and a CRN header the guard requires but no caller sends.

## Positive Observations

- The degrade-open / fail-closed split is the right call and is directly asserted by both unit tests and ITs.
- `NotificationContentSnapshotMapper` uses MapStruct `DeepClone` with `unmappedTargetPolicy = ERROR`, so amend/cancel-amend picked the new fields up automatically with no snapshot gap.
- The `schemaVersion` bump is complete and consistent — it is produced in exactly one place, no consumer pins `"1"`, and the tests-repo E2E was updated in lockstep.
- `NotificationModelSerialisationTest` is a good new addition, covering camelCase round-trip and legacy payloads without the new fields.

## Test Coverage

- **Unit tests:** good behavioural naming and real assertions (inertness pin, degrade-open vs fail-closed, distinct messages, metric counters). Every case uses a single party with a single `operatorId`, so `.distinct()` de-duplication, multi-party accumulation and mixed DELETED+NOT_FOUND are untested; AMEND is unexercised on both new paths; and the non-2xx to `UNAVAILABLE` branch has no test despite the service branching on it.
- **Integration tests:** present and well-shaped, but `IntegrationBase` registers `operators.url` as `<mockserver>/operators/` while the client already appends `/operators/{id}`, so the ITs exercise a doubled path production can never produce. The wildcard `.*/{id}` stubs hide it, and MockServer's default 404 means two "404 to unresolved" tests would pass even if the service never called the API.

## Risk Assessment

**Overall Risk:** Medium-High
**Rationale:** The `RestClient.Builder` sharing can silently apply 1s/2s timeouts to cdp-uploader file streaming, and the operators URL is wrong in the stack — both are runtime faults that no current test would catch.
