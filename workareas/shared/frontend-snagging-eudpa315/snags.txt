# Frontend snagging — EUDPA-315
#
# One snagging comment per line, written however you'd say it out loud.
# Blank lines and lines starting with # are ignored.
#
# Write them as complaints, not as instructions. "the hint under the radios is
# gone" is a better input than "add a hint to the radios" — the first lets the
# investigator find the real cause, the second pre-commits it to a fix that may
# be wrong.
#
# The text is matched verbatim to decide what has already been triaged, so
# editing a line after its subtask exists will raise a second one. Append
# rather than rewrite.
